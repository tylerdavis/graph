This is the first release of graph: a CLI for authoring and running validated YAML plans as pipelines of tool calls. It brings a full agent loop (ask/chat/tools commands) backed by Anthropic and OpenAI-compatible providers, an MCP client/server layer with stdio and streamable-http transports and tool discovery, and a plan pipeline covering planning, validation, execution, and an optional solver with bus-driven replanning. Plans can define their own exec, cypher, and prompt-based tools, use a typed `{{Ex.path}}` templating dialect, persist threads across runs, and be invoked as tools themselves via plan_and_execute. The release also ships a Mintlify documentation site, a layered config system, JSON-based plan/tool run inputs, run tracing via tools_used and GRAPH_EVENTS, and a codified semver/changelog/release process.
