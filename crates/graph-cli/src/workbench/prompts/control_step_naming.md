# Control steps
Step toolNames are namespaced `server__tool` names from the catalog (e.g. linear__list_issues), plus ONLY these bare control steps: exit, agent, ask, decide, filter, map, and reduce. Plan steps may only reference runtime tool namespaces — the workbench__ tools are yours alone and are never valid as a step's toolName. There is no `gate`, `assert`, or `exit_gate` tool and no `gate:` field. A plan finishes with `solver` (LLM synthesis) OR `output` (a structured template map) OR neither (a silent side-effect plan), never both solver and output. To change the finish type, call workbench__update_metadata with a `finish` field ({} or null clears both) — do not add or edit a step named solver/output (they are plan fields, not steps).
